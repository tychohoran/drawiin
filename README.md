# Drawiin.space — Frontend Prototype

Structure et prototype visuel pour **drawiin.space**, plateforme multidisciplinaire indépendante située dans la forêt de Carthage Mohamed Ali.

## Structure du site

1. **Home / Manifesto:** Présentation générale et ancrage territorial à Carthage Mohamed Ali.
2. **01. Public Programming:** Social formats, chess club, soap workshops, sound sessions & curated screenings (Efest, Salt, eSseda + Hors-les-murs).
3. **02. Print & Publications:** Micro-édition, projets autonomes, éditions collaboratives et impressions.
4. **03. Permaculture & Situated Ecologies:** PDC avec Maha Mouelhi, jardin communal et marché pop-up.
5. **04. About / Team:** Présentation des rôles de Sara Bouzgarrou et Fredj Moussa.

## Note pour la direction graphique (Sara)
Ce code utilise **Tailwind CSS via CDN** dans un seul fichier HTML pour permettre une prévisualisation directe sans installation ni compilation. 

Les choix typographiques, palettes et grilles intégrés ici servent de base de travail pour l'identité visuelle et le layout de la plateforme web.
